# Scope Document - TechCup

## System

TechCup es una plataforma digital para la gestión de torneos de fútbol de la Escuela Colombiana de Ingeniería Julio Garavito

## Problem to be Solved

Actualmente no existe una plataforma centralizada que permita gestionar torneos, registrar equipos, procesar pagos y generar reportes de inscripción

../uml/context-diagram.png

## System Scope

El sistema permitirá:

- Crear torneos.
- Actualizar torneos.
- Cambiar el estado de los torneos.
- Registrar equipos.
- Actualizar información de equipos.
- Realizar pagos mediante PSE.
- Validar pagos.
- Generar reportes de equipos inscritos.
- Generar reportes de ingresos por inscripciones.
- Enviar reportes a la Decanatura.

### Fuera del alcance

- Gestión de partidos.
- Programación de encuentros.
- Gestión de árbitros.
- Estadísticas deportivas.
- Registro de resultados.
